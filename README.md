# Lode

> There is no knowledge base, there is a lode filled with ore.

Lode is a local-first knowledge mining engine that turns your workspace into a searchable knowledge lode.

# Why Lode?

Your knowledge already exists in:

- Documentation that explains concepts and decisions.
- Markdown files containing project notes.
- Design documents describing systems and workflows.
- Text files and other written materials accumulated over time.

The challenge is not creating more knowledge bases. It is finding and retrieving the knowledge that already exists.

Lode helps agents access this knowledge by turning your workspace documents into a searchable knowledge lode.

Instead of relying only on general knowledge, agents can retrieve the information that is specific to your projects.
